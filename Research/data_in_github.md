# Dr. B.R. Ambedkar - GitHub Source Index

This document is a curated collection of public GitHub sources related to Dr. B.R. Ambedkar, including speeches, books, writings, tribute websites, biography-oriented projects, and related digital archives.

Important note:
- GitHub does not appear to have a large canonical archive for Dr. Ambedkar like a full film archive or an official speech repository.
- Most relevant public sources are:
  - static tribute / biography websites
  - offline knowledge bases
  - book / writing collections
  - constitutional legacy pages
  - educational or AI-driven content around his ideas

- `Ambedkar movie`
- `Ambedkar documentary`
- `Ambedkar film`
- `Babasaheb film`
- `Ambedkar speech OR speeches OR lectures OR talks`

Conclusion:
- GitHub is much stronger on tribute websites and static biography pages than on cinematic or documentary production material.
- For actual movie/documentary content, the better sources are likely:
  - YouTube
  - Wikimedia Commons
  - public video archives
  - official educational collections
  - academic repositories or institutional archives
